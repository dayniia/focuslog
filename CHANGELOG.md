# Changelog

All notable changes to **FocusLog** will be documented in this file.

## [1.0.0] - 2026-02-09

### Added
- **Focus Dashboard**: A central hub featuring a personalized greeting, current streak tracking, and quick stats.
- **Library (Mastery Tracking)**: A dedicated space to manage skills with custom categories, status tracking, and progress sliders.
- **Active Mastery**: Highlights your most recent active skill on the dashboard for immediate focus.
- **Today's Focus (To-Do List)**: A new daily task manager integrated directly into the dashboard for granular progress tracking.
- **History (Activity Log)**: A clean timeline view grouped by date to visualize your consistency and milestones.
- **Dynamic Categories**: Users can now define their own learning categories, with smart filtering that adapts to your unique journey.
- **FocusLog Branding**: Introduced a custom logo and brand identity focused on "Mastery starts here."
- **Persistence**: All data is automatically saved to local storage, ensuring privacy and offline availability.

### Changed
- **Visual Identity**: Complete overhaul to a "Premium Lofi" aesthetic. Switched to a warm neutral palette (`#f2efea`) with sage green accents (`#82937a`).
- **Typography**: Upgraded to a modern font stack using *Manrope* for displays and *Inter* for body text.
- **Navigation**: Cleaned up the sidebar with minimalist labels ("Library", "History") and improved icon weights.
- **Component Design**: Refined cards, buttons, and modals with soft radii, subtle shadows, and smooth transitions.

### Fixed
- **Mobile Responsiveness**: Implemented a sliding mobile sidebar with overlay for smaller screens.
- **Chart Performance**: Optimized the consistency overview chart with smooth gradients and better tooltip responsiveness.
- **Empty States**: Added helpful prompts and visuals for when the Library or History is empty.
